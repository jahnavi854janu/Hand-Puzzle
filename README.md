# 🧩 Hand Puzzle – AI-Powered AR Puzzle Game

An interactive **Augmented Reality (AR) Puzzle Game** powered by **MediaPipe AI** that allows users to play entirely using **hand gestures** without a mouse or touchscreen.

Using real-time **AI hand tracking**, players capture an image from the webcam, which is automatically converted into a puzzle. The puzzle is then solved using natural **pinch-and-drag gestures**, creating an immersive browser-based AR gaming experience.

---
# ✨ Features

## 🖐 AI Hand Tracking
- Real-time hand detection using **MediaPipe AI**
- Smooth gesture recognition
- Works directly in the browser

## 📷 Gesture-Based Image Capture
Create a **Director's Frame** using:
- Left Thumb
- Left Index Finger
- Right Thumb
- Right Index Finger

Open all fingers to:

- Capture image
- Automatically crop selected region
- Remove hands from captured image

No buttons required.

# 🌟 Game Controls

| Gesture | Action |
|----------|--------|
| Director's Frame | Select capture area |
| Open Palm | Capture image |
| Pinch | Grab tile |
| Drag | Move tile |
| Release | Drop tile |
